# Equipo4-Curso-Ing

Este es el repositorio oficial del proyecto web desarrollado con Angular 18 y TypeScript elaborado por los integrantes del Equipo 4.

## Instalacion
1. Clona este repositorio.
2. Ejecuta npm install para descargar las dependencias.
3. Levanta el servidor local con ng serve.

## Requisitos previos
* Node.js (v20 o superior)
* Angular CLI (npm install -g @angular/cli)
